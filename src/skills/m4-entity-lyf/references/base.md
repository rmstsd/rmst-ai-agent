# 基础标签页配置详解

业务对象编辑界面的「基本」标签页，编辑的是 `EntityMeta` 元数据对象。本文中的“对应字段”指保存到 `meta/entity` 接口的 JSON 字段路径；嵌套字段使用点号表示，例如 `actions.createDisabled`。

## 基本配置区

### 实体名

- **对应字段**：`name`
- **含义**：业务对象的英文唯一标识，例如 `FbWarehouse`、`Material`。
- **作用**：系统识别业务对象的名称，也是前端打开列表、详情页和调用实体接口时使用的业务对象名。

### 显示名

- **对应字段**：`label`
- **含义**：界面显示的业务对象名称，例如“仓库”“物料”。
- **作用**：列表、页面标题、引用选择等界面显示。

### 组

- **对应字段**：`group`
- **含义**：业务对象所属的分组标识。
- **作用**：参与业务对象菜单或管理列表的分组。
- **常见分组**：`MainData`、`Warehouse`、`WCS`、`Core`、`Falcon`、`GW`、`User` 等。

### 已停用

- **对应字段**：`disabled`
- **含义**：停用整个业务对象元数据。
- **作用**：管理界面和菜单构建时会过滤已停用的业务对象；它不是业务数据行的 `btDisabled` 字段。

### Builtin

- **对应字段**：`builtin`
- **含义**：标记该业务对象是否为系统内置对象。

### 定制数据源

- **对应字段**：`otherDatasource`
- **含义**：标记业务对象是否使用定制数据源。

### 数量关系

- **对应字段**：`scale`
- **选项**：
  - `Instances`：多值，普通列表数据。
  - `Hierarchical`：层级数据，树形结构。
  - `Singleton`：单例数据，通常只有一条。
- **默认值**：`Instances`。

### 有停用/禁用功能

- **对应字段**：`disabledFilter`
- **含义**：是否为业务数据提供停用/启用能力。
- **作用**：保存修复元数据时，如果为 `true`，前端会自动补充通用字段 `btDisabled`；引用查询也会根据该配置默认过滤停用数据。
- **注意**：这里的 `disabledFilter` 是“启用数据行停用功能”，和上面的元数据字段 `disabled` 不是同一个配置。

### 默认排序

- **对应字段**：`sort`
- **含义**：列表和引用查询使用的默认排序表达式。
- **示例**：`-createdOn` 表示按创建时间倒序；多个排序条件按项目约定使用逗号分隔。

### 启用回收站

- **对应字段**：`trash`
- **作用**：控制删除数据是否进入回收站。

### 启用历史版本

- **对应字段**：`history`
- **作用**：控制是否保留业务对象的历史版本。

### 启用修改记录

- **对应字段**：`trackChange`
- **作用**：控制是否记录业务对象修改记录。

### 启用评论

- **对应字段**：`commentEnabled`
- **作用**：控制详情页是否启用评论功能。

### 新增编辑界面提示语

- **对应字段**：`editTip`
- **作用**：配置新增、编辑界面的提示文本。

### 列表界面提示语

- **对应字段**：`indexTip`
- **作用**：配置列表界面的提示文本。

### 弃用

- **对应字段**：`deprecated`
- **作用**：标记该业务对象已弃用，供管理和配置逻辑识别。

## 编号及排序规则

### 启用自动编号

- **对应字段**：`idGen.enabled`
- **作用**：新增数据时启用自动编号。

### 编号前缀

- **对应字段**：`idGen.fixedPrefix`
- **作用**：配置自动编号使用的固定前缀。
- **注意**：启用自动编号时，保存前要求该字段非空。

### 流水号位数

- **对应字段**：`idGen.flowNoWidth`
- **作用**：配置流水号数字部分的位数，例如 `5` 可生成 `00001`。
- **默认值**：`4`。

### 默认排序

- **对应字段**：`sort`
- **说明**：该字段已经在[基本配置区](#基本配置区)列出，这里只说明它与编号配置并列显示在基本页中。

## 禁用配置区

这些配置项保存于 `actions` 对象中，勾选表示禁用对应操作。

| 界面配置项 | 对应字段 | 勾选后的效果 |
| --- | --- | --- |
| **禁用创建** | `actions.createDisabled` | 禁止新建业务数据 |
| **禁用更新** | `actions.updateDisabled` | 禁止编辑已有业务数据 |
| **禁用批量编辑** | `actions.batchUpdateDisabled` | 禁止批量编辑多条数据 |
| **禁用删除** | `actions.removeDisabled` | 禁止删除业务数据 |
| **禁用导出** | `actions.exportDisabled` | 禁止导出业务数据 |
| **禁用导入** | `actions.importDisabled` | 禁止导入业务数据 |

## 页面及菜单配置

### 替换详情页

- **对应字段**：`detailsPageName`
- **含义**：自定义详情页的页面标识。
- **作用**：非空时，前端通过该页面标识打开自定义详情页，而不是标准 `EntityViewPage`。

### 详情页打开方式

- **对应字段**：`viewOpenMode`
- **可选值**：
  - `Dialog`：对话框。
  - `Page`：页面。
- **作用**：没有替换详情页时，控制标准详情页以对话框还是页面打开；移动端会直接使用页面方式。

### 首页是操作页面

- **对应字段**：`opIndex`
- **含义**：标记业务对象首页是否作为操作页面使用。类型定义中的注释是“首页是操纵（新增）界面”。

### 图标

- **对应字段**：`menuIcon`
- **作用**：配置菜单项使用的图标。

### 颜色

- **对应字段**：`menuColor`
- **作用**：配置菜单项使用的颜色。

### 不作为菜单项

- **对应字段**：`notMenu`
- **作用**：业务对象仍然存在，但菜单构建时不作为菜单项显示。

## 摘要配置

### 摘要字段列表

- **对应字段**：`digest.fields`
- **含义**：用于生成业务对象简短描述的字段名列表。
- **作用**：用于引用下拉、消息通知和关联数据显示。
- **注意**：列表中的每个字段名必须存在于当前业务对象的 `fields` 中。

### 摘要格式化代码

- **对应字段**：`digest.formatJs`
- **含义**：可选的摘要格式化 JavaScript 代码。
- **作用**：存在时由 `ev` 参数生成自定义摘要；未配置时按 `digest.fields` 的值拼接。

## 数据清理

数据清理配置也位于「基本」标签页。

| 界面配置项 | 对应字段 | 说明 |
| --- | --- | --- |
| **启用** | `dateClean.enabled` | 是否启用数据清理 |
| **保留天数** | `dateClean.keepDays` | 启用后填写数据保留天数 |
| **数据清理范围** | `dateClean.filter` | 使用复杂查询配置清理范围 |

`dateClean.type` 是数据清理类型，当前类型定义为 `ByDay`；基本页当前没有单独渲染该字段。

## 系统通知与扩展代码

### 通知事件

通知配置保存于 `userNotice` 对象中：

| 界面配置项 | 对应字段 |
| --- | --- |
| **新增** | `userNotice.create` |
| **修改** | `userNotice.update` |
| **评论** | `userNotice.comment` |
| **通知目标字段** | `userNotice.targetUserFields` |

`targetUserFields` 是字段名数组。前端只把当前业务对象中 `type === "Reference"` 且 `refEntity === "HumanUser"` 的字段作为通知目标选项。

`EntityChangedUserNotice` 类型中虽然保留了 `userNotice.delete`，但当前基本页的删除通知复选框已被注释，界面上不能直接配置该项。

### 表格样式扩展代码

- **对应字段**：`listTableStyleExt`
- **所在标签**：`扩展代码`
- **作用**：自定义列表表格样式和交互。

### 业务对象改变后处理代码

- **对应字段**：`onChangeJs`
- **所在标签**：`扩展代码`
- **作用**：业务对象数据发生变化后执行的前端处理代码。

## 常见问题

### Q: “实体名”和“显示名”分别对应哪个字段？

A：实体名对应 `EntityMeta.name`，显示名对应 `EntityMeta.label`。前者是系统识别业务对象的唯一标识，后者是界面展示名称。

### Q: 为什么新增按钮不见了？

A：检查 `actions.createDisabled` 是否为 `true`。

### Q: 为什么删除按钮不见了？

A：检查 `actions.removeDisabled` 是否为 `true`。

### Q: 为什么编号没有自动生成？

A：检查 `idGen.enabled` 是否为 `true`，并确认 `idGen.fixedPrefix` 和 `idGen.flowNoWidth` 已正确配置。

### Q: 为什么引用下拉中没有停用数据？

A：检查被引用业务对象的 `disabledFilter`。启用该配置后，引用查询默认过滤 `btDisabled != true` 的数据。

### Q: 修改记录在哪里看？

A：检查 `trackChange` 是否启用；详情页是否显示修改记录还取决于对应页面实现。

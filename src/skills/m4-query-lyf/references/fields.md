# 字段标签页配置详解

业务对象编辑界面的「字段」标签页，定义该业务对象有哪些数据字段，以及每个字段的行为规则。这是最常用、配置项最多的标签页。

## 字段列表操作

左侧为字段列表区域：

| 操作 | 说明 |
|------|------|
| **添加字段** | 新增自定义字段，字段名只能字母数字，必须字母开头（小驼峰） |
| **添加常用字段** | 快速添加系统预置字段：ID、创建人、创建时间、最后修改人、最后修改时间、停用等 |
| **创建组件业务对象** | 快速创建单据的"单行"子对象（如入库单→入库单行），自动建立关联 |
| **调整顺序** | 拖拽或填写字段显示序号，顺序与列表页、详情页、单行表格一致 |

> 💡 建议：尽量使用"添加常用字段"，避免漏配 ID、创建时间等系统字段。

## 字段基础属性

### 显示名
- **含义**：界面上显示的字段标签（如"物料名称"、"入库数量"）
- 可用中文、英文等

### 类型
- **含义**：字段的数据类型，决定输入方式和存储方式
- 详见下方[字段类型说明](#字段类型说明)

### 多值
- **含义**：字段值是否为数组（可存多个值）
- **效果**：
  - 图片类型：可上传多张图片
  - 文本类型：可添加多个文本录入框
  - 引用类型：变为多选
  - 组件类型：必须勾选，以表格形式呈现单行
- **配套配置**：列表最少多少项、列表最多多少项，限制数量范围
- **典型场景**：单据的单行字段（必须多值）、物料的多张图片、多个标签

## 字段类型说明

| 类型 | 适用场景 | 输入方式 | 备注 |
|------|----------|----------|------|
| **文本** | 名称、备注、编号、地址 | 文本框/文本域 | 最常用 |
| **整数** | 数量、序号、次数 | 数字输入框 | |
| **浮点数** | 价格、重量、尺寸、坐标 | 数字输入框 | 需配置小数位数，默认 3 位 |
| **布尔** | 是否停用、是否启用、是否锁定 | 开关/下拉 | 列表显示"是/空"，可定制显示文字和图标 |
| **日期** | 单据日期、创建日期 | 日期选择器 | |
| **时间** | 精确到时分秒的时间 | 时间选择器 | |
| **图片** | 物料图片、凭证照片 | 图片上传 | 支持多值（多张图） |
| **文件** | 附件、合同、文档 | 文件上传 | 支持多值 |
| **引用** | 关联其他业务对象（供应商、仓库、物料） | 下拉选择/弹窗选择 | 需配置引用实体，可设置引用筛选 |
| **组件** | 单据单行、嵌套子表 | 表格形式 | 必须勾选多值，关联单行业务对象 |

### 类型选择注意事项
- 选了文本/整数/浮点数/布尔/日期/时间/图片/文件后，**输入方式自动匹配**，无需手动选
- 选了**引用**，必须配置"引用实体"（关联哪个业务对象）
- 选了**组件**，必须勾选多值，并选择关联的单行业务对象
- 布尔类型可定制 true/false 的显示文字、图标、CSS 样式

## 填写规则

### 选项清单
- **作用**：配置下拉选项，字段以下拉框形式录入
- **配置**：添加多个选项，每个选项有值和显示文字
- **典型场景**：状态字段（未提交/已提交/已完成）、类型字段（采购入库/产成品入库）

### 默认值
- **作用**：新增数据时自动填充的初始值
- **示例**：状态字段默认"未提交"，类型字段默认"采购入库"

### 必填
- **作用**：新增/编辑时该字段必须填写，否则不能保存
- **注意**：必填校验在保存时触发，会提示具体哪个字段未填

### 停用
- **作用**：临时停用该字段，不删除数据，但界面不显示、不参与校验
- **使用场景**：某个字段暂时不用，但历史数据需要保留

### 模糊筛选
- **作用**：列表页快速搜索时，是否匹配该字段的值
- **建议**：编号、名称等关键字段勾选，备注等长文本不勾选

### 小数位数
- **适用**：浮点数类型
- **含义**：保留几位小数
- **默认值**：3

## 智能联动

### 引用字段自动带出
实现"选择 A 后自动填充 B"的效果。

| 配置项 | 作用 | 示例 |
|--------|------|------|
| **引用字段：本业务对象检测字段** | 选择哪个引用字段作为触发源 | 选"物料"字段 |
| **引用字段：取值路径** | 从引用对象中取哪个字段的值 | 填 `name`，选择物料后自动带出物料名称 |

**配置示例**：采购单详情页，选择物料后自动带出物料名称、规格、型号。
- 物料名称字段：检测字段选"物料"，取值路径填 `name`
- 物料规格字段：检测字段选"物料"，取值路径填 `spec`

### 汇总单行字段
- **作用**：单头字段自动汇总所有单行的某个字段值
- **配置**：填写单行业务对象中要汇总的字段名
- **典型场景**：采购单头的"总数量"自动汇总所有单行的采购数量；"总金额"自动汇总所有单行的金额

### 计算公式
- **作用**：基于其他字段做公式计算，自动填充当前字段
- **典型场景**：单行的"金额" = 单价 × 数量
- **配置**：填写计算公式表达式

### 字段改变后触发扩展代码
- **作用**：字段值变化时执行前端脚本，实现复杂联动
- **典型场景**：选择物料后，自动查询该物料在当前仓库的库存，填充到"建议库位"字段
- **配置**：在该字段的"扩展代码"中填写前端 JS 代码
- **示例代码结构**：
```javascript
// 根据物料查询库存，填充建议库位
const oldBin = await ctx.utils.getStoreBinIdOfMaterial(ctx.newFv)
const storeBin = ctx.ev["storeBin"] || oldBin
return { suggestBin: oldBin, storeBin: storeBin }
```

## 显示控制

### 查看/新建/编辑 三种页面状态
每个字段可分别配置在三种页面中的状态：

| 状态 | 含义 |
|------|------|
| **不显示** | 该页面完全看不到这个字段 |
| **只读** | 能看到值，但不能修改 |
| **可编辑** | 能看到且能修改 |

> 💡 有快捷组合按钮，一键设置常用组合（如"查看只读，新建编辑可编辑"）。

### 输入方式
- **作用**：新增/编辑页面的录入控件类型
- **常见选项**：文本框、文本域、下拉、密码、日期选择器等
- **密码类型**：显示为 `····`，且列表页不显示该字段

### 特殊输入
- **作用**：调用特殊前端组件（高级功能）
- 一般无需配置

### 宽显示
- **作用**：详情页中该字段占据整行宽度
- **默认**：多列布局，字段按列排列
- **典型场景**：备注、地址等长文本字段勾选宽显示

### 字段显示顺序
- **作用**：数字序号，控制字段排列顺序
- **影响范围**：列表页字段顺序、详情页字段顺序、单行表格列顺序，三处一致

## 列表表格控制

| 配置项 | 作用 |
|--------|------|
| **列表表格禁用** | 勾选后该字段不在列表页表格中显示（但详情页仍可显示） |
| **列表表格宽度** | 该字段在列表页的列宽（单位 px） |
| **列表表格对齐** | 左对齐 / 居中 / 右对齐 |
| **组件表格列宽度** | 单行业务对象中，该字段在单行表格里的列宽（单位 px） |

---

## 数据库配置

| 配置项 | 作用 |
|--------|------|
| **SQL 数据类型** | 数据库中字段的类型（VARCHAR、INT、DECIMAL、TEXT 等） |
| **最多字符** | 文本类型的最大长度（如 VARCHAR(50)） |
| **数字位数** | 数值类型的总位数 |
| **小数位数** | 数值类型的小数位数 |

> ⚠️ **重要**：修改这些配置后，必须执行以下操作才能生效：
> - 非现场环境：业务对象列表页点击「更新数据库结构」
> - 现场环境：重启 M4 服务
> 
> 如果不执行，会出现"改了字段不生效"、"数据库报错"等问题。

## 引用筛选

如果字段是**引用类型**，可配置筛选条件，只显示引用对象中符合条件的数据。

- **作用**：过滤下拉选项，避免选到不相关的数据
- **示例**：
  - "入库仓库"字段只显示类型为"原料仓"的仓库
  - "供应商"字段只显示已启用、未停用的供应商
- **配置方式**：设置引用对象的字段匹配条件

## 批量操作按钮

对于**布尔类型**或**有选项清单**的字段，可配置列表页的批量操作按钮。

### 配置方式
1. 在字段配置页找到"列表界面批量按钮"
2. 点击"添加"
3. 填写：
   - **按钮文字**：如"解锁"、"批量标记已完成"
   - **值**：点击后将字段设为什么值（布尔型勾选/不勾选，选项型选哪个值）
   - **按钮类型**：默认/主要/警告（决定颜色）
4. 保存业务对象

### 典型场景
- 库存明细的"锁定"字段 → 批量解锁按钮
- 库位的"停用"字段 → 批量启用/停用按钮
- 任务的"状态"字段 → 批量标记完成按钮

## 常见问题

### Q: 为什么字段在列表页不显示？
A: 检查以下几项：
1. 字段是否被"停用"
2. 是否勾选了"列表表格禁用"
3. 字段输入方式是否为"密码"（密码类型列表不显示）
4. 字段显示顺序是否正确

### Q: 为什么新增页面看不到某个字段？
A: 检查字段的"新建"页面状态是否设为"不显示"。

### Q: 为什么引用下拉是空的？
A: 检查：
1. 引用实体是否配置正确
2. 是否配置了引用筛选，筛选条件太严格导致没有符合条件的数据
3. 引用对象本身是否有数据

### Q: 为什么必填字段没填也能保存？
A: 检查：
1. 是否真的勾选了"必填"
2. 字段是否在当前页面被设为"不显示"（不显示的字段不校验必填）
3. 是否通过 API 直接创建（API 调用可能绕过部分前端校验）

### Q: 为什么改了字段类型/长度后不生效？
A: 修改数据库相关配置后，必须点击「更新数据库结构」（非现场）或重启服务（现场）。

### Q: 选择物料后怎么自动带出名称和规格？
A: 在名称、规格字段中配置"引用字段：本业务对象检测字段"选物料，"取值路径"分别填 name、spec。

### Q: 怎么实现多行明细（单据单行）？
A: 
1. 创建单行业务对象（如入库单行）
2. 在单头业务对象中添加字段，类型选"组件"，勾选多值，引用实体选单行对象
3. 单行业务对象中必须有"所属订单"字段，引用回单头对象
4. 或直接用"创建组件业务对象"按钮快速创建

### Q: 布尔字段在列表里显示什么？
A: 默认 true 显示"是"，false/null/undefined 显示为空。可在字段配置中定制 true/false 的显示文字、图标和样式。
